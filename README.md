# Instoryview Plugin (preview)

Plugin bundle for hosts that support local Plugin installation (for example the Codex desktop app). It contains the Instoryview Skill and the remote MCP configuration (`https://instoryview.com/mcp`, OAuth).

**Preview:** it is not yet listed in any public Plugin Directory. If your host cannot import the bundle, add `https://instoryview.com/mcp` as a remote MCP connector with OAuth instead.

```bash
git clone https://github.com/instoryview/chatgpt-plugin
codex plugin marketplace add ./chatgpt-plugin
```

See `plugin/INSTALL.md`. Docs: https://instoryview.com/docs/plugins
